# Sales Dashboard Excel Project

## Overview
This project is an interactive Sales Dashboard built in Microsoft Excel. The dashboard helps analyze sales performance across different categories, years, states, customers, and monthly trends.

## Features
- Interactive Slicers for filtering data
- Sales by Category Analysis
- Profit Gained Over Time
- Sales by State Map Visualization
- Customer Count Analysis
- Top 5 Customers Making Profit
- Monthly Sales Trend Analysis

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Map Charts
- Data Visualization Techniques

## Dashboard Insights
- Compare sales across product categories.
- Analyze profit trends over multiple years.
- Identify top-performing states.
- Track customer count by year.
- Monitor monthly sales performance.
- Find top profit-generating customers.
